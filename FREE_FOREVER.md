# Free Forever

The vastlint CLI will always be free to use. This is a public commitment, not just a license clause.

What "free" means here:

The CLI binary is free to run for any purpose — local development, CI pipelines, internal ad serving infrastructure, production systems, commercial products. No usage limits. No feature gating.

The `vastlint-core` library is free to use in any project, open-source or proprietary, under the Apache 2.0 license. Embed it, ship it in your SDK, run it in your ad server. No royalties, no restrictions.

What will never happen:

- A paid tier that hides rules
- A "cloud" version that requires an account
- Rate limiting on the CLI
- Telemetry without explicit opt-in
- A license change that retroactively restricts existing versions

The Apache 2.0 license requires attribution — keep the NOTICE file and copyright header in any distribution. That is the only obligation.

If you use vastlint in production and find it useful, the only thing asked in return is to report bugs and contribute rule improvements when you can.
